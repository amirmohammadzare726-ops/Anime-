# ETERNUM — جهانِ سرنوشت‌های نانوشته

بازی رول‌پلی متنی فانتزی تاریک. این مخزن پایهٔ وب، حساب کاربری و ذخیرهٔ امن مسیر بازی را فراهم می‌کند.

## فایل‌ها
- `index.html`: رابط وب فارسی و ورود/ثبت‌نام با نام کاربری.
- `supabase/schema.sql`: جدول پروفایل، ایجاد خودکار پروفایل و سیاست‌های دسترسی.
- `.github/workflows/pages.yml`: انتشار خودکار روی GitHub Pages.

## انتشار رایگان
1. برو به **Settings → Pages**.
2. در **Build and deployment**، گزینهٔ **GitHub Actions** را انتخاب کن.
3. بعد از اجرای workflow، آدرس سایت در همان صفحه نشان داده می‌شود.

## راه‌اندازی دیتابیس مستقل
1. در [Supabase](https://supabase.com/) یک پروژهٔ جدید فقط برای ETERNUM بساز. پروژه‌های بازی‌های دیگر را استفاده نکن.
2. در SQL Editor پروژهٔ جدید، فایل `supabase/schema.sql` را اجرا کن.
3. در Authentication settings، غیرفعال‌کردن تأیید ایمیل برای این نسخهٔ آزمایشی ضروری است؛ ورود با نام کاربری از شناسهٔ داخلی `username@accounts.eternum.invalid` استفاده می‌کند و ایمیل واقعی از بازیکن نمی‌خواهد.
4. در `index.html` مقدارهای `SUPABASE_URL` و `SUPABASE_ANON_KEY` را با Project URL و publishable/anon key پروژهٔ جدید عوض کن.
5. هرگز کلید `service_role` یا کلید محرمانه را در فایل عمومی قرار نده.

## وضعیت و امنیت
- پس از تنظیم Supabase، ثبت‌نام/ورود و ذخیرهٔ انتخاب مکان به پروفایل حساب متصل می‌شود.
- سیاست‌های دیتابیس اجازه نمی‌دهند مرورگر مستقیماً سطح شخصیت یا سطح قدرت را تغییر دهد؛ این پیشرفت‌ها باید از منطق سمت سرور پیاده شوند.
- حساب‌ها در این نسخه بازیابی با ایمیل واقعی ندارند؛ پیش از استفادهٔ عمومی باید روش بازیابی امن طراحی شود.
- هوش مصنوعی واقعی، ساخت آزاد قدرت، چت چندنفره، نبرد آنلاین و دنیای مشترک هنوز پیاده‌سازی نشده‌اند.
- GitHub Pages فقط فایل‌های وب را میزبانی می‌کند؛ پایگاه داده و منطق سرور جداگانه‌اند.
